# 发音与语调：纯文本教学要点

场景里每场只挑 **1 个**发音点，用 §1 的标注法写出来，配一句"跟读 2 遍"。下面是挑点和讲解的弹药库。

## 1. 标注法速查

| 现象 | 写法 | 例子 |
|---|---|---|
| 词重音 | 目标音节**大写** | `pho-TOG-raphy`、`re-SERVE`、`ˈRE-cord`（名词） |
| 弱读 | `原词 → 弱读形` | `to → tə`、`and → ən`、`of → ə`、`can → kən`、`for → fə` |
| 连读 | `‿` 连接 | `pick‿it‿up`、`not‿at‿all` |
| 语调 | `↗` / `↘` | `You're coming↗?` / `Where are you going↘?` |

不要把整句 IPA 音标串甩给用户，也不要音标教程。**最多一行标注 + 一句跟读指令。**

## 2. 四个高频问题（按优先级挑）

### ① 词尾辅音吞掉
中文音节以元音收尾，用户常把词尾 -ed/-s/-t 吞掉，导致时态和单复数听不出来。
- 案例：`I work` 说成 `I worked` → 听成 `I walk`
- 纠法：先说清"词尾要留一口气"，再给对比：`work /wɜːrk/` vs `worked /wɜːrkt/`，`book` vs `books /bʊks/`
- 提示语：*Keep the ending — say it like it has a little tail.*

### ② 长短元音混
- 案例：`ship /ʃɪp/` vs `sheep /ʃiːp/`；`full /fʊl/` vs `fool /fuːl/`
- 纠法：短元音"紧、快、憋住"，长元音"拉长、带滑动"。用最小对立词组连读 3 遍
- 提示语：*Short one is clipped, long one has a glide.*

### ③ 词重音错位
- 典型：`REcord`（名词）vs `reCORD`（动词）；`PERmit` vs `perMIT`；`pho-TOG-raphy`（第三音节）
- 长词规律：双音节名词重音多在第一音节，动词多在第二音节；-tion/-ic 结尾重音在前一音节
- 提示语：*Hit the stressed syllable harder and higher, flatten the rest.*

### ④ 句调平或一律降
- 中式习惯：整句平调；或所有问句都用降调，听起来像审问
- 规则：
  - 陈述句 → 末词降 `↘`
  - Yes/No 问句 → 句尾升 `↗`
  - Wh- 问句（what/where/why）→ 降 `↘`
  - 列举未完 → 升，最后一项 → 降（`apples↗, oranges↗, and pears↘`）
  - 礼貌请求 → 升（`Could you help me out↗?`）
- 提示语：*Wh- questions go down. Yes/no questions go up.*

## 3. 连读三规则（讲到才有用，别主动开课）

1. **辅音 + 元音**：前词尾辅音和后词首元音合并 → `pick‿it‿up`、`turn‿it‿off`
2. **同化**：`don't you → don'cha`、`did you → didja`、`want to → wanna`、`going to → gonna`（口语听力必知，但**提示用户别在正式场合用**）
3. **虚词弱读**：介词、冠词、助动词在句中几乎都弱读 → `a → ə`、`the → ðə`、`to → tə`、`can → kən`、`was → wəz`
   - 注意 `can` 与 `can't`：`can` 弱读成 `kən`，`can't` 保留清晰的 `kænt`，这是中级用户最容易听反的一对

## 4. 语调练习小设计（1 分钟，别超过）

在场景里现场用，不要另起一节：
1. 用户说了一句话 → 你标出重音词和句调
2. 给一次"慢速版 + 正常版"对比（只标重音大写，如 `I didn't SAY that.` vs `I didn't say THAT.`）
3. 用户跟读一遍 → 只说 `Good` 或指出唯一一个还没到位的点

不要连续纠正 3 个发音点，一场一个就够。
